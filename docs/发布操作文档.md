# dumate-api 发布到 GitHub 操作文档

## 前置条件

### 1. 安装 Git

从 [git-scm.com](https://git-scm.com/downloads) 下载 Windows 安装包，双击安装，一路默认选项即可。

安装后验证：

```bash
git --version
# 输出: git version 2.xx.x
```

如果 Git 安装在非标准路径（如 `D:\Git\bin\`），需要将 `bin` 目录添加到系统环境变量 `PATH` 中，否则终端找不到 `git` 命令。

### 2. 安装 gh CLI

gh CLI（GitHub CLI）是 GitHub 官方命令行工具，用于创建仓库、管理认证、提 PR 等操作。

**方法一：MSI 安装（推荐）**

从 [GitHub CLI 发布页](https://github.com/cli/cli/releases) 下载 `gh_X.X.X_windows_amd64.msi`，双击安装。

**方法二：便携版**

下载 `gh_X.X.X_windows_amd64.zip`，解压到任意目录（如 `C:\Tools\gh-cli`），将 `bin` 目录加入系统环境变量 `PATH`。

验证安装：

```bash
gh --version
# 输出: gh version 2.65.0 (2025-01-06)
```

### 3. 认证 gh CLI

```bash
gh auth login --web
```

终端会输出一段设备码：

```
! First copy your one-time code: XXXX-XXXX
Open this URL to continue in your web browser: https://github.com/login/device
```

浏览器打开 `https://github.com/login/device`，输入设备码，点击 **Authorize** 授权。授权完成后终端会显示登录成功。

验证认证状态：

```bash
gh auth status
# 输出: ✓ Logged in to github.com account YourName (keyring)
```

> **注意**：如果本地配置了 HTTP 代理（如 8888 透传代理），gh CLI 可能因代理拦截 HTTPS 请求而失败。此时需要临时清除代理环境变量后再执行认证：
>
> ```bash
> set HTTP_PROXY=
> set HTTPS_PROXY=
> gh auth login --web
> ```

## 发布流程

### 1. 清理项目目录

删除不属于源码的杂散文件：探针脚本、运行时产物、日志、大文件等。

| 类型 | 示例文件 | 处理方式 |
| --- | --- | --- |
| 探针脚本 | `probe_*.py`, `extract_*.py` | 删除 |
| 运行时产物 | `*.pid`, `*.log`, `token.txt` | 删除 |
| 大文件 | `opencode_copy.db`（125MB） | 删除 |
| 有用测试 | `test_*.py` | 移到 `tools/` 目录 |

### 2. 配置 .gitignore

确保敏感文件和运行时产物不会被提交到仓库：

```gitignore
# 机密信息
token.txt
auth.json
.cookie-key
*.pem
*.key

# 运行时产物
*.pid
*.log
__pycache__/
*.pyc
.venv/
venv/

# 本机专用启动脚本（含本机路径，参考 README 自行生成）
启动DuMateAPI.bat

# 探针 / 探索产物
opencode_copy.db
probe_*.py
extract_*.py
list_tables*.py
read_env.py
schema.py
asar_out/
```

### 3. 初始化 Git 仓库

```bash
cd dumate-api
git init
git config user.email "yourname@example.com"
git config user.name "YourName"
```

### 4. 添加文件并提交

```bash
git add -A
git commit -m "feat: initial release - DuMate API v0.1.0"
```

### 5. 创建 GitHub 仓库

```bash
gh repo create dumate-api --private --description "项目的简短描述"
```

参数说明：
- `--private`：创建私有仓库（公开仓库用 `--public`）
- `--description`：仓库描述（可选）

### 6. 推送代码

```bash
# 添加远程仓库
git remote add origin https://github.com/YourName/dumate-api.git

# 配置 gh 作为 git 凭证管理器（避免重复输入密码）
gh auth setup-git

# 推送
git push -u origin master
```

> 如果推送时提示 `terminal prompts disabled` 或认证失败，说明 git 凭证未正确配置。运行 `gh auth setup-git` 后重试即可。

## 常见问题

### gh CLI 网络请求失败（unexpected EOF）

原因：本地 HTTP 代理拦截了 gh 的 HTTPS 请求。先清除代理环境变量，再执行 gh 命令：

```bash
set HTTP_PROXY=
set HTTPS_PROXY=
gh repo create dumate-api --private
```

### git push 提示 "User cancelled dialog"

原因：git 凭证管理器未正确配置，且终端处于非交互模式。运行 `gh auth setup-git` 配置凭证后重试。

### 推送成功但仓库为空

检查是否忘记 `git add` 和 `git commit`，或 `.gitignore` 误配导致所有文件被忽略。
